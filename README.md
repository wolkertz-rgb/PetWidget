# PetWidget — живой питомец на рабочем столе Android

Прямоугольный виджет с автономным питомцем-блобом (в духе Pou).
Питомец сам решает, что делать: гуляет, садится, спит, играет с предметами.
Предметы (17 штук: 10 игрушек + 7 еды) случайно появляются в комнате,
питомец подходит и взаимодействует с ними: нюхает, ест, толкает, играет.

## Как питомец экономит батарею

- Симуляция **тикает только при включённом экране**. Экран погас —
  всё останавливается и состояние сохраняется, процесс ничего не делает.
- Для анимации рисуются только кадры в маленький Bitmap виджета,
  с адаптивной частотой (действие — чаще, сон — реже).
- Это foreground-сервис с тихим уведомлением IMPORTANCE_MIN —
  телефон не будит, wake lock'ов нет.
- После перезагрузки телефона питомец продолжается с сохранённого состояния
  (позиция, действия, предметы — в SharedPreferences).
- Если телефона не было включённым дольше 4 часов — питомец по-настоящему
  «спал» и после возвращения немного досыпает.

## Взаимодействие

- **Тап по виджету** — питомец прыгает от радости (если не спит — его нельзя будить).

## Предметы

| Игрушки | Еда |
|---|---|
| Мячик (катается), Кубик, Кости, Шарик (плавает), Мишка, Робот (лампочка мигает), Ракета, Кораблик, Цветок (в горшке), Юла | Пицца, Суши, Пончик, Печенье, Кофе (пар идёт), Яблоко, Мороженое |

Появление: случайно, максимум 2 предмета в комнате, живут 1.5–3.5 минуты.

## Как собрать APK (нужен один раз Android Studio)

1. Установи [Android Studio](https://developer.android.com/studio) (в комплекте JDK и эмулятор — не нужны).
2. Открой папку проекта: **File → Open → C:\Users\sting\PetWidget**.
   Дай Studio скачать Gradle (первый синк занимает пару минут).
3. Собери: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
4. Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`.
5. Скинь APK на телефон (через кабель/мессенджер) и установи
   (разреши установку из неизвестных источников).
6. Долгое нажатие на рабочем столе → **Виджеты → Питомец** → перетащи на стол.
   Растяни виджет как нравится — питомец подстроится.

## Структура кода

| Файл | За что отвечает |
|---|---|
| `PetSim.kt` | Мозг: состояния, ИИ решений, физика предметов, сохранение |
| `ItemDefs.kt` | Каталог 17 предметов и их векторная отрисовка |
| `SceneRenderer.kt` | Художник: комната, стены/пол, предметы, сам питомец |
| `PetService.kt` | Кадры жизни (только при включённом экране), вкл/выкл экрана |
| `PetWidgetProvider.kt` | Виджет: добавление, тапы, статичный запасной кадр |
| `BootReceiver` | Возобновление жизни после перезагрузки телефона |
