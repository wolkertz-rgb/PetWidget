# SPEC: Visual-v3 — редизайн моделек, пета, света и анимаций

*Владелец согласовал направление 03.11.2026: «редизайн моделек, еды и игрушек,
вплоть до самого пета + переработка анимаций + растушёвка света лампочки и
теней + более ясные блики и эмоции — гладко и без багов». Статус: на утверждении.*

## Objective
Комната, питомец и предметы читаются как один «мягкий игрушечный» мир:
объёмный свет от лампы с честными тенями, читаемые эмоции,模型-иконки без
«сырости». Прочность контрактов важнее новизны: 14 тем, ход мыслей PetSim
и автономность не меняются.

## Границы художественного стиля
- Язык: «мягкая игрушка» — скруглённые силуэты, единая ширина обводки,
  два-три тона + блик на предмет, контактная тень под каждым.
- Силуэт пета (блоб + антенна) СОХРАНЯЕМ — идентичность. Редизайн = объём,
  лицо, plasticity, не новая анатомия.
- Частотный закон (из SPEC-анимаций): осцилляции ≤ 2 Гц при 20 FPS.
- Все цвета — только через существующие тема-токены (`th()`), иначе тем
  14 пресетов ломаются.

## Срезы (порядок = ратчет: каждый тронутый блок переезжает в свой файл)

### 1. Свет и тени (`Lighting.kt` ← фрагменты SceneRenderer)
- Лампа: двухслойное свечение (горячее ядро + широкий ореол), тёплое пятно
  на полу с мягким краем, зыбкое мерцание ≤ 0.3 Гц
- Конусы god-rays — аккуратные, с градиентом по оси, без «эллипсов-пятен»
- Контактные тени: под мебелью, под каждым предметом (alpha ∝ расстоянию
  от пола), угловая проработка комнаты (тени углов — старый бэклог)
- Полумрак ночью → синий градиент + контраст тёплого при свете

### 2. Лицо и эмоции (`PetFace.kt`)
- Единая геометрия эмоций (сейчас 6 вариантов глаз разбросаны): каждая
  эмоция = именованная функция, брови/зрачки/вектор взгляда
- Ясность: радость — дуги + зрачки-щёлочки; хитрец — прищур + блик;
  смущение — зрачки убегает; голод — бровки + слезинка плавная
- Блик глаза: двухступенчатый specular (крупный + микро-точка)

### 3. Тело пета (`PetBody.kt`)
- Объём: трёхточечный градиент — **реанимируем токен `pet_mid`** (зомби из
  аудита: пресеты его пишут, рендер молчал) как серединный тон
- Rim-light по направлению к лампе (дуга вместо полного контура),
  мягкая тень-основание, блик-стеклянность аккуратнее
- Пластичность: squash/stretch при ходьбе/приземлении остаётся пружиной

### 4. Игрушки (`ItemArt.kt`, пачка 1)
ball, block, dice, balloon, plushie, robot, rocket, boat, flower, top —
единый язык: тень, объём 2+1 тона, блик; у ракеты — честное сопло.

### 5. Еда и подарок (`ItemArt.kt`, пачка 2)
pizza, sushi, donut, cookie, coffee, apple, icecream, box — плюс «у укуса»
(еда чуть вжимается к морде при откусе — читается процесс, а не таяние).

### 6. Анимации под новые модели
- Падение с потолка: микро-вращение + приземистый squash (есть) + пыли
  (есть) — довести кривые easing
- Подъём в лапы: по дуге с лёгким наклоном (сейчас линейный lift)
- Ракета «пытается улететь»: подъём-падение с тряской ≤ 2 Гц, пламя живее
- Кости: тряска кубика по-честному (угол, не дрожь позиции)

## Команды
- CI: push → Actions ( assembleDebug + lintDebug + testDebugUnitTest )
- Локальной сборки нет (нет JDK/SDK на машине) — проверка глазами владельца
  на телефоне после каждого среза + зелёный run.

## Testing Strategy
- PetSim не трогаем — 8 характеризационных тестов обязаны остаться зелёными
- Рендер: визуальный приём = владелец смотрит срез-APK; критерии по срезу
  перечислены в таблице выше
- После срезов 1–3 — smoke-чек всех 14 тем на превью ателье (цвета не
  поехали), скрин-чек дня/ночи и свет-вкл/выкл

## Boundaries
- **Always:** тема-токены; атомарные коммиты; открытие сборки в OpenCode;
  частотный закон анимаций
- **Ask first:** возврат «пяток-няшек» (владелец их когда-то удалил!),
  любые изменения силуэта пета, изменение числа состояний
- **Never:** сторонние библиотеки; растровые ассеты; поведение PetSim;
  переписывание истории git

## Success Criteria
1. Комната выглядит освещённой, а не «закрашенной»: тень/свет читаются,
   углы не сливаются
2. Эмоция пета определяется с одного взгляда за ≤ 0.5 с
3. Каждый предмет узнаваем в 40-пиксельной сетке виджета
4. Новый предмет подписывается именем на ~1.7 с при появлении — угадывать не приходится
5. 14 тем красят редизайн без единого «осколка» цвета
6. CI зелёный на каждом срезе; поведение питомца — один в один до/после
