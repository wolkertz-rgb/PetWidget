# 🎬 СПРАВОЧНИК АНИМАЦИЙ ПИТОМЦА (для ручного редактирования)

Файлы, где живут анимации:
- **Мозг/переходы:** `app/src/main/java/com/sting/petwidget/PetSim.kt` (функции `tick`, `nextAction`, `beginInteract`, `finishInteract`, `beginPull`, `finishPull`, `spawnItem`, `tap`)
- **Рисование поз/лиц/рук:** `app/src/main/java/com/sting/petwidget/SceneRenderer.kt` (`petCy`, `drawPet`, лицо внутри `drawPet`, `drawArms`)

Правило понимания: **каждая анимация — функция времени**:
- `animPhase` — общие «секунды жизни» (глобальный маятник: покачивания, дыхание)
- `stateTime` — сколько мс в текущем состоянии (0..stateDur) — локальный прогресс `p = stateTime / stateDur`
- `p` почти везде прогоняется через `smooth(p) = p·p·(3−2p)` (мягкие края)

## 1. КАРТА ПЕРЕХОДОВ (кто в кого переходит)

Всё решает `nextAction()` — вызывается, когда закончилось время состояния:

```
[ЛЮБОЕ состояние закончилось] ──→ nextAction():
  1) если проснулся после сна (woke) ────────────→ STRETCH (потягушки) 50%
  2) есть НОВЫЙ предмет (age<12с, нетронутый) ───→ WALK→TO_ITEM (85% — любопытство!)
  3) есть любой нетронутый предмет ──────────────→ WALK→TO_ITEM (62%)
  4) трюк-рулетка (кулдаун 30 сек) ──────────────→ ROLL / SWAY / LOOK / STRETCH
  5) иначе ───────────────────────────────────────→ WALK-RANDOM / SIT / IDLE / SLEEP
```

Специальные переходы (не через nextAction):
- **Спавн предмета** (`spawnItem`) → мгновенно WALK→TO_ITEM (любопытство сильнее всего)
- **Голоден >75 и еды нет** → HUNGRY (жалоба, каждые 45 сек)
- **Минута прошла** (`lastPullAt`) → WALK→TO_SWITCH → **PULL** (тяга шнура → свет щёлкает)
  - после тяги: 30% шанс «детской серии»: HAPPY(650мс) → PULL → HAPPY → … (2–4 раза) → TICKLE (финальный смешок)
- **Тап по питомцу** → `tap()` → случайная реакция: HAPPY(сердечки) / SMUG / BLUSH / SQUEEZE / TICKLE
- **Досыпание**: экран был выключен >4 часов → SLEEP (8–18 сек) при возвращении
- Взаимодействие с предметом завершено → HAPPY(700мс) → nextAction
- Серия тяги: HAPPY-пауза → `pendingNextPull` → обратно в PULL

**Длительности (stateDur, мс):** STRETCH 1600 / WALK-к-предмету 14000–16000 / WALK-RANDOM 4000–9000 /
SIT 3000–8000 / IDLE 2000–5000 / SLEEP 5000–16000 / ROLL 1300 / SWAY 2100 / LOOK 1600 /
WAVE 2400 / PULL 1400 (щелчок на 700) / HUNGRY 2800 / HAPPY 700–1000 / реакции тапа 1000–1600

## 2. ВЕРТИКАЛЬ (petCy) — «прыжки и бобы»

```kotlin
private fun petCy(sim, floorY, unit, r): Float {
    val onBed = sim.state == SLEEP && sim.sleepingInBed
    var cy = floorY - r * 0.92f - if (onBed) unit * 0.62f else 0f   // в кресле сидит выше

    if (HAPPY)  cy -= sin(π * p) * (r * 1.5f)          // прыжок-радость (парабола)
    if (WALK)   cy -= |sin(animPhase * 5.5)| * r * 0.14f // шаг: частый мелкий боб
    if (ROLL)   cy -= sin(π * smooth(p)) * r * 0.5f      // кувырок: полёт по дуге
    if (WAVE)   cy -= |sin(stateTime / 280)| * r * 0.12f // приветствие: лёгкое подпрыгивание
    if (PULL)   cy -= sin(π * min(1, t/500)) * r * 0.85f // прыжок к шнуру (хват)
    return cy
}
```
**Что крутить:** `5.5` — частота шага; `1.5` — высота прыжка; `0.85` — высота прыжка к шнуру.

## 3. ПОЗА ТЕЛА (в drawPet, `when(st)`) — наклоны и пружины

```kotlin
WALK   sx = 1 + 0.05·sin(animPhase·11)        // горизонтальная пружина шага
       sy = 1 − 0.035·sin(animPhase·11)       // вертикальная (сжатие-растяжение)
SLEEP  sx = 1 + 0.03·sin(animPhase·1.2)       // медленное дыхание
       sy = 1 − 0.02·sin(animPhase·1.2)
INTERACT sx = 1 + 0.05·sin(stateTime / 50)    // возня с предметом: дрожь интереса
ROLL   // антиципация! 3 фазы:
       p<0.14 → sy = 1 − 0.16·smooth(p/0.14)              // приседает
       0.14<p<0.86 → rot = smooth(...)·2π·dir;            // сам кувырок (полный оборот)
                     cy −= sin(π·rp)·r·0.5
       p>0.86 → sy = 1 − 0.14·sin(...)                    // приземление-отскок
SWAY   osc = sin(p·π·4)                     // 2 полных покачивания
       rot = osc·0.30; dx = osc·unit·1.1
LOOK   headTilt = sin(p·π·1.2)·0.10         // голова наклоняется «прислушиваясь»
WAVE   sx = 1+0.04·sin(t/240); sy = 1+0.03·sin(t/240)
SMUG   sx = 1+0.05·sin(t/300); dx = unit·0.15·dir·smooth(t/300)  // выпятиться
BLUSH  sx=1+0.04·sin(t/250); sy=1−0.04·sin(t/250)   // съёживается
SQUEEZE sx=1−0.07·sin(t/130); sy=1+0.07·sin(t/130) // блаженная желе-пружина
TICKLE cy −= |sin(t/120)|·r·0.9; sx=1+0.08·sin(t/60)   // пружинистый хохот
HUNGRY sx=1+0.04·sin(t/90); sy=1−0.03·sin(t/90)        // дрожь жалобы
IDLE/прочее sx=1+0.02·sin(animPhase·1.5)               // тихое дыхание
```

**Плавность переходов (главное!):** после `when(st)` все значения проходят
экспоненциальное сглаживание к прошлой позе (`lastPose`, коэффициент `k = dt·9`,
по углу — через кратчайшую дугу). Новые состояния ВСЕГДА начинаются с нейтральной позы —
поэтому переходы бесшовные. **Не делай в новых анимациях стартовых скачков: начинай с 0.**

При смене действия у морды рисуется белый «пуф» (`facePuff`) — мультипликационная дымка.

## 4. ЛИЦО (в drawPet после тела)

**Глаза** — приоритет веток:
```
SLEEP → закрытые дуги + ротик + «Z z z» (три буквы всплывают)
STRETCH/WAVE/SQUEEZE/TICKLE/HAPPY → дужки-глаза («улыбка глазами»)
  + TICKLE: золотая искра-слеза смеха
BLUSH → полоски + украдкой смотрит вбок (маленькие зрачки со смещением −dir)
иначе (открытые глаза) → варианты из кастомизации:
  classic: зрачок + 2 блика
  shine:   огромный блик + искра снизу
  sleepy:  зрачок ниже + веко цвета тела (полукруг) + линия века
  round:   крупный ровный зрачок + один блик
Зрачки СЛЕДЯТ: lookX/lookY тянутся к целевому предмету; в LOOK — сканируют из стороны в сторону
Цвет зрачков: токен look_eyecolor
```

**Брови:** при голоде >70 — «домиком» (две наклонные линии); у SMUG — одна поднята.

**Щёчки:** форма из кастомизации: circles (овалы) / stripes (2 скруглённые полоски) / hearts (мини-сердечки); при BLUSH — крупнее и ярче (grow 1.35, альфа 0xB4).

**Рот:**
```
SLEEP → маленький кружок
WAVE → открытая «D»-улыбка с язычком
SMUG → кривая ухмылка (наклон 8°) 
BLUSH → крошечная улыбочка
SQUEEZE → блаженный «о»
TICKLE → широкий хохот
PULL → до щелчка: сосредоточенная полоска; после: дужки + улыбка
HUNGRY → волнистая жалоба
HAPPY/INTERACT(не еда) → по кастомизации look_grin: smile / open(D+язык) / neutral / ooh
EAT/SMELL(еда) → открытый рот у еды, у SMELL ещё «пары»
спокойствие → по кастомизации look_mouth: wide / dimples(+точки) / tooth(+белый зуб) / small; 
              при голоде >70 — грустная дуга
```

**Антенна:** ball (шарик с бликом) / flower (5 лепестков вращаются вокруг центра) /
string (длинная нить с узелком) / none. Цвет: токен look_ante.

## 5. РУКИ (drawArms)

Рука = кривая Безье от «плеча» (точка на боку тела: cx ± r·0.55, cy + r·0.18)
к ладошке-кружку (радиус 0.24·unit) с двойным штрихом: свечение 0.40 + контур 0.22.
Ограничение длины: максимум **2.15·r** от центра тела (руки не тянутся бесконечно).

```
STRETCH  обе руки вверх (высота по синусу растяжки), арка сверху
WAVE     правая рука над головой, машет: hx = cx + r·1.1 + sin(t/230)·unit·0.6
PULL     рука схватила бусину шнура: рука тянет к tipY (шнур провисает на 0.85·unit)
INTERACT:
  SMELL/LIFT/EAT → обе ладони ДЕРЖАТ предмет у точки хвата (предмет летит к питомцу)
  RUB  → ручки КРУЖАТ над предметом (две фазы: a = animPhase·6 и +π)
  OPEN → руки тянутся к крышке подарка и поднимают её
  PUSH/PLAY → обе ладони упираются в предмет (толчок)
```

## 6. ПРЕДМЕТЫ (кратко)

- **Спавн:** тень-телеграф (0.5с) → падение с потолка (easeInQuad) → 2 отскока → пыль
- **Физика:** экспоненциальное трение `vx·=exp(−1.6·dt)`, стены отскакивают ×0.5
- **Спавн-веса:** голоден → еда 75/25; сыт → игрушки 75/25
- **Подарок:** питомец открывает → крышка улетает с вращением → предмет с конфетти
- **Еда:** у каждой свой масштаб/наклон/боб при поедании + крошки (pizza/cookie/donut/apple/icecream/coffee/sushi)
- **Игрушки:** ball/block/top вращаются при катании, robot вибрирует+искра, plushie пружинит+сердечко, flower кланяется+искры, dice трясётся, balloon взлетает, rocket flame+подъём, boat качается

## 7. ШПАРГАЛКА ПО КРУТИЛКАМ

| Хочу | Крутить |
|---|---|
| Быстрее ходит | `PetSim.WALK_SPEED` (0.075) |
| Чаще играет с предметами | `nextAutoInteract` расписание: `rF(90,150)` → меньше |
| Чаще трюки | убрать `nextTrickAt` кулдаун / поднять порог 0.70 |
| Чаще машет | `nextWaveEvery rL(240_000, 360_000)` |
| Чаще дёргает свет | `lastPullAt`-правило: 60f → меньше |
| Выше прыжки | petCy: коэффициенты при r (1.5/0.85…) |
| Сильнее дрожь смеха | TICKLE: `sin(t/60)` амплитуда 0.08 |
| Глубже присед-кувырок | ROLL фаза 0.14: коэффициент 0.16 |
| Голод быстрее | `HUNGER_FULL_MS` (600_000) |
| Съедено за раз больше | `HUNGER_EAT_RELIEF` (65) |
