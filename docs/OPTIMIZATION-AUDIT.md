# Аудит нагрузки — 2026-11-04

## Выполнено

- PreviewView: цикл кадров явно останавливается в onPause и возобновляется в onResume. После возврата время первого кадра сбрасывается.
- SceneRenderer: предпросмотр больше не записывает pet_pose в общие SharedPreferences (persistPose=false). Симуляция предпросмотра уже использовала autoSave=false.
- PetWidgetProvider.burst: при живом PetService не создаётся вспомогательный HandlerThread, который раньше только выполнял пропущенные advanceAndRender; callback завершения вызывается сразу.
- SceneRenderer: 11 Paint для градиентов переиспользуются отдельно для каждого слоя и экземпляра рендера. Shader продолжает обновляться: изменение размеров и цветов не требует ручного сброса кеша.
- Массив lastPose обновляется на месте вместо выделения нового массива каждый кадр.
- Удалены недостижимый facePuff (все присваивания давали ноль), связанное состояние, неиспользуемые blinking, headTilt и импорт RadialGradient.

## Сохранено намеренно

- Частота сервиса 20 кадров/с: её снижение изменило бы плавность. Сервис уже останавливает кадры при выключении экрана.
- Запись позы сервисом раз в секунду: нужна для восстановления после смерти процесса.
- Keep-alive и резервное рисование: обеспечивают работу после остановки сервиса.
- Пользовательские HTML, история Git, старые ресурсы и документация не удалялись. ic_launcher по-прежнему используется уведомлением.

## Границы проверки

Проверка исходников и GitHub Actions (сборка, Lint, существующие тесты). Замеры CPU, памяти, батареи на реальном телефоне не выполнялись; процент ускорения не заявляется.

Дальнейшие направления отдельной работы: адресная отрисовка разных размеров нескольких виджетов (сейчас сервис берёт размер первого); сокращение пересылок Bitmap через AppWidgetManager, если пользователь допустит другую частоту; кеширование неизменяемых градиентов с корректной инвалидацией.
