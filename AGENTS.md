# PetWidget — правила работы ИИ-агента

Формат проекта: владелец формулирует суть — код пишет агент. Код: Kotlin,
сторонних библиотек нет, вся графика векторно на Canvas.

## Сборки (GitHub Actions)

- Сборка запускается на каждый push в `main` и `visual-v2`; артефакт —
  `petwidget-apk` на странице Actions (~4–6 мин).
- **После каждого push агент обязан открыть страницу нового run'а
  в браузерной вкладке OpenCode** (`browser.tabs.open`, URL вида
  `https://github.com/wolkertz-rgb/PetWidget/actions/runs/<run_id>`)
  — владелец следит за прогрессом и сразу скачивает APK.
- Run id: `GET https://api.github.com/repos/wolkertz-rgb/PetWidget/actions/runs?branch=<ветка>&per_page=1`.
- Если сборка красная — чинить коммитом поверх; ветку не откатывать,
  историю не переписывать.

## Дисциплина кода

- Атомарные коммиты (~10–100 строк), сообщения по-русски, повествованием.
- Характеризационные тесты `PetSimTest` — защита рефы; менять поведение
  только под ними.
- Мёртвый код: искать перед удалением, спрашивать владельца про спорное.
